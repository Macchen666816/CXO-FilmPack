# Native RAW black and white probes

Generated by `tools/build_raw_bw_fixtures.py` from owned FilmPack native probes.
The manifest records all input hashes. The three CXORAW01 fixtures contain
17³ camera inputs, sensor outputs and final encoded-working outputs plus native
repaired grid/runtime post; they do not fit colors or package a photo LUT.

`kodaktrix400.parameters.bin` uses test-only CXORBW01: EV and rendering-EV,
three 3×3 pre/post/extra matrices, film curve, composed inverse curve, and native
repaired grid. It lets `verifyRawBw` construct Tri-X using the product catalog's
`preTransform * ElitePre`, catalog curve/post, independent inverse and baker,
then compare rendered grayscale to the real native runtime oracle.

BW node hue is unstable when saturation is near zero; the production bake
verification measures final grayscale output and logs S/V error instead of
requiring undefined hue to match. `runtimeBw` explicitly performs gray before
postcurve/Naka. Curves used to undo the post during baking must never be passed
as the runtime forward postcurve.
