# CXO FilmPack 1.0.1

## 中文

- 修复 Apple ProRAW DNG 无法导入的问题，已验证 iPhone 15 Pro Max 的 IMG_3046.DNG。
- 接入 ProRAW 线性显影与 RAW 胶片核心，修正导入和选择胶片后的明显色差。
- 精简编辑界面的冗余说明，保留底部处理进度、耗时和错误显示。

K40 与 ARM64 模拟器的 Apple DNG 导入、胶片、颗粒、后处理、JPEG/TIFF 保存及取消回归通过。对同一张样片，Original 和 Portra400 相对本机 DxO 的同坐标 sRGB 通道 RMSE 分别为 0.30 / 255、0.39 / 255；详见仓库技术记录。

Android 8.0+。已有相同正式签名的版本可直接覆盖安装。版本号为 1.0.1，versionCode 为 33。

下载 APK 即可使用，颗粒已内置。`native-grain8-v1.cxograinpack` 是源码构建资源；从源码构建时放入项目的 `releases/` 目录。LibRaw 源码附件用于对应第三方源码提供。SHA256SUMS.txt 包含附件校验值。

当前不支持 JPEG XL ProRAW、含 HueSat/Look 表或三光源配置的 Apple DNG。普通相机 RAW 需满足对应机身与胶片适配条件。项目原创材料禁止商用，第三方材料适用各自许可。

## English

- Fixed Apple ProRAW DNG import, verified with IMG_3046.DNG from an iPhone 15 Pro Max.
- Added the linear ProRAW development route and RAW film pipeline, correcting the visible color mismatch on import and film selection.
- Removed redundant editor labels while retaining progress, processing times and errors.

Apple DNG import, films, grain, post-processing, JPEG/TIFF export and cancellation passed on a K40 and an ARM64 emulator. On the tested image, Original and Portra 400 achieved same-coordinate sRGB channel RMSE values of 0.30 / 255 and 0.39 / 255 against the local DxO reference.

Requires Android 8.0+. Existing installations with the same release signature can be updated in place. Version 1.0.1, versionCode 33.

Install the APK; grain is bundled. The grain-pack attachment is only needed for source builds and belongs in the project's `releases/` directory. SHA256SUMS.txt contains asset checksums. JPEG XL ProRAW, HueSat/Look profiles and triple-illuminant Apple DNG profiles are not currently supported.
